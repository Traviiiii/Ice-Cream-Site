# Ice Cream Site
This is a small website, made as a brief demo to show off AI Coding Assistants. The goal was to get something presentable with as few prompts and in as short time as possible.

The website can be viewed via [Github Pages](https://traviiiii.github.io/Ice-Cream-Site/)

---

Outside of 2 visual human tweaks to improve consistency and fix an image, this website was entirely generated by Codex across 6 prompts. The initial prompt specified a loose design as follows:

> Generate me a website for an ice cream store. Create custom CSS files and Javascript as you see fit. Use a colourful colour scheme, link to external images. Have a JS submission contact form. Add a home, menu, contact and gallery pages. Social links in the footer.

---

5 Follow up prompts were then issued which used similar language, avoiding heavy technical details and using human language. The features changed were:
- Change the 5 pages to be seperated rather than all subsections of the main page
- Add a Google maps Embed to the Contact page
- Add an active navigation class
- Ensure navigation appears the same across all pages
